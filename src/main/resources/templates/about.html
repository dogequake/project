О приложении

Приложение

Веб-приложение «Учёт серверной инфраструктуры» позволяет вести список серверов и площадок (ЦОД), а также рассчитывать годовую стоимость содержания каждого сервера (амортизация, электроэнергия с учётом PUE, аренда места в стойке, лицензии).

Технологии: Java 17, Spring Boot 2.7, Spring MVC, Spring Security, Spring Data JPA, Thymeleaf, H2, Lombok, Actuator.

Роли

  • READ_ONLY - просмотр всех данных, без изменений;
  • USER - видит и изменяет только созданные им записи;
  • ADMIN - полный доступ и управление ролями.
